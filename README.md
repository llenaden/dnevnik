# Дневник тела

Личный дневник тренировок и самочувствия в виде одной веб-страницы, которую удобно открыть с телефона и добавить на экран «Домой».

## Что умеет

- **Сегодня.** Рекомендация, что тренировать в этот день, мои тренировки со ссылками на YouTube, таблетки и отчёт дня.
- **Отчёт дня:**
  - боль по шкале от 0 до 10: спина, живот, руки, ноги, суставы;
  - вес;
  - комментарий;
  - питание по продуктам. Каждый продукт подсвечивается по логике low-FODMAP (можно / немного / избегать), калории и БЖУ считаются приблизительно.
- **Сводка.** Дни, недели и месяц: серия недель, дни с тренировками, график веса, продукты, которые могли беспокоить живот, таблетки за месяц.
- **Таблетки.** Трекер привычки по неделям и полный календарь приёма по месяцам.
- **Цикл.** Месячные, близость, прогноз следующих месячных, овуляции и фертильных дней.
- **Журнал.** Статьи о чекапе, теле и питании, плюс свои заметки с выбором иконки.
- **Профиль:**
  - итоги и достижения;
  - моя норма калорий и БЖУ, с учётом беременности;
  - план недели;
  - выгрузка и загрузка данных.

## Где хранятся данные

На GitHub Pages данные хранятся **только в браузере** (localStorage) того устройства, где ими пользуются. Чтобы не потерять записи или перенести их на другое устройство:

1. В профиле нажми **«Выгрузить данные»**. Скачается JSON-файл.
2. На другом устройстве нажми **«Загрузить данные»** и выбери этот файл.

Если очистить данные сайта в браузере, записи пропадут, поэтому выгружай их время от времени.

## Как опубликовать на GitHub Pages

1. Создай репозиторий на GitHub, например `dnevnik-tela`.
2. Загрузи в него все файлы из этой папки (кнопка **Add file → Upload files** или `git push`).
3. Открой **Settings → Pages**. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
4. Через минуту сайт появится по адресу `https://<твой-логин>.github.io/dnevnik-tela/`.
5. На iPhone открой адрес в Safari, нажми **Поделиться → На экран «Домой»**. Приложение откроется без адресной строки, с иконкой лотоса.

Через `git`:

```bash
cd dnevnik-tela
git init
git add .
git commit -m "Дневник тела"
git branch -M main
git remote add origin https://github.com/<твой-логин>/dnevnik-tela.git
git push -u origin main
```

## Структура

```
index.html            готовая страница (её и открывает GitHub Pages)
manifest.webmanifest  настройки для установки на экран «Домой»
icons/                иконка приложения и фавикон
src/                  исходники, из которых собирается index.html
  template.html       разметка, стили и логика
  articles.js         статьи журнала
  foods.js            база продуктов: КБЖУ и оценка для кишечника
  glyphs.js           нарисованные глифы интерфейса
  glv.js              иконки из открытых наборов Iconify
  vec.js              векторные иконки и их оптическое выравнивание
build.py              сборка index.html из src/
```

## Как вносить правки

Правь файлы в `src/`, затем собери страницу:

```bash
python3 build.py
```

Нужен только Python 3, сторонние пакеты не нужны. После сборки закоммить обновлённый `index.html`.
